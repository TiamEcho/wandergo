# WANDERGO · Fly Me to the World

> 旅游攻略打卡平台 —— AI 帮你规划，地图带你走，用户真实打卡

## 🔗 在线体验

**https://tiamecho.github.io/wandergo/**

点击即可直接访问，无需注册登录（站内「登录/注册」为本地演示账号系统）。

## 功能一览

- 🗺️ **3D 实景地图**：中国地图（按省彩色）+ 世界地图，emoji 景点标点、涟漪航线，点击标点看攻略
- 🤖 **AI 旅行规划**：提问后自动生成景点 / 出行方式 / 价格规划 / 打卡视频 / Plog 推荐模块卡
- 💬 **社区动态**：融合抖音、小红书、快手、Instagram、YouTube 平台内容，Vlog/Plog/图文，话题热度榜与人群适配图表
- 📖 **专题路线**：跟着小说去旅行 · 跟着小王子去旅行
- 🧳 **旅行工作台**：手账工坊（AI 生成/自由创作、PNG 导出）· 协同计划（机酒识别、记账分摊、投票）· 小众文创素材库
- 🔍 **全站搜索**（Ctrl+K）：视频/Vlog/Plog/书籍地点/景点/话题/店铺
- 🎨 **主题工坊**：5 套预设 + ins 风/国风色卡 + 自定义色轮 + AI 智能配色
- 🎵 **BGM 曲库**：9 种曲风合成音乐，视频播放页自由切换

## 本地运行

纯静态前端，无需构建。双击 index.html 即可；或 python -m http.server 本地起服务。

## 目录结构

`
index.html      页面结构
css/style.css   全站样式 + 主题系统
js/data.js      景点/帖子/话题/店铺等数据
js/app.js       地图/AI/社区/工作台/搜索等逻辑
`

## 说明

本站为前端演示项目：登录态、社区数据、协同计划等「后端」能力均通过浏览器 localStorage 模拟，数据保存在访问者自己的浏览器中。
